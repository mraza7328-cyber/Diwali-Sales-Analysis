# Diwali Sales Analysis

## Project Overview
This project analyzes Diwali sales data using Python.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains customer, sales, order, occupation,
state and product category information.

## Project Workflow
1. Data Import
2. Data Cleaning
3. Missing Value Analysis
4. Exploratory Data Analysis
5. Data Visualization
6. Business Insights

## Conclusion
This project provides useful insights into customer behavior
and Diwali sales patterns.
